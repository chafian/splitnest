# Agent icons

SVG files copied unchanged from [developer-icons](https://github.com/xandemon/developer-icons) (MIT License, Copyright (c) 2024 Sandesh Katwal aka xandemon; see LICENSE in this folder), downloaded from the repository's `icons/` folder on 2026-11-03.

They are logos of third-party products and are used only to identify which AI agent CLI is running in a terminal tab. Checked before use: no scripts, event handlers, external references or `foreignObject`.

- `claude-ai.svg`: Claude Code
- `openai.svg`: Codex (shown as a monochrome mask so it is visible on the dark theme)
- `gemini.svg`: Gemini CLI
- `github-copilot.svg`: GitHub Copilot CLI (monochrome mask)
- `cursor-light.svg`: Cursor Agent
