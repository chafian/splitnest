# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/chafian/splitnest/security/advisories/new)
for this repository, not in a public issue. Include what you found, how to reproduce it, and the
SplitNest version.

You can expect an acknowledgement within a week. SplitNest is maintained by one person, so fixes are
released as soon as practical; you will be told the plan and credited in the release notes unless you
prefer otherwise.

## Supported versions

Only the latest release receives fixes. Starting with version 0.2.0, SplitNest checks for updates
and installs them automatically unless you turn that off (Settings → About).
